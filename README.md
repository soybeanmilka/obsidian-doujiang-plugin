# 🍅 豆浆的小插件 (sidebar-timer)

一个 Obsidian 番茄钟小插件：番茄计时 + 待办计划 + 学习统计 + 日历热力图，全部数据本地存储，轻量无依赖。

## 功能

- **番茄计时**：可暂停/继续/停止，支持「真实时间」与「仅软件运行」两种倒计时模式
- **休息倒计时**：番茄熟了之后，点击弹窗提示文字直接开始休息倒计时（时长可设置），休息结束弹窗提示可一键开始下一轮
- **状态栏常显**：运行中显示倒计时 ⏳，暂停显示 ⏸，空闲显示今日 🍅 战绩
- **待办计划**：支持计划日期（今天 / 已过期 / 以后 / 已完成分组），可在日历上安排未来的事
- **学习统计**：今日 / 近 7 天柱状图 / 本月与累计合计
- **日历热力图**：月历格子颜色深浅 = 当天学习分钟数，蓝点 = 当天有待办，点击查看当天详情
- **可拖动面板**：按住标题栏可把弹窗拖到屏幕任意位置
- **可爱动效**：标题 🍅 摇摆、到点弹窗蹦跳入场（尊重系统"减少动态效果"设置）

## 安装

### 方法一：BRAT（推荐）

1. 安装 [BRAT](https://obsidian.md/plugins?id=obsidian42-brat) 插件
2. 命令面板运行 `BRAT: Add a beta plugin for testing`
3. 输入本项目的 GitHub 仓库地址，回车即可

### 方法二：手动安装

1. 到本项目的 [Releases](../../releases) 页面下载最新 `main.js`、`manifest.json`、`styles.css`
2. 在笔记库 `.obsidian/plugins/` 下新建文件夹（如 `sidebar-timer`），把三个文件放进去
3. 重启 Obsidian 并启用插件

## 使用

- 点击左侧边栏的沙漏图标：开始 / 停止倒计时
- 点击右下角状态栏（🍅 或 ⏳）：打开面板（待办 / 统计 / 日历 三个标签）
- 命令面板：
  - `打开豆浆面板` — 打开统计面板
  - `快速添加待办` — 打开面板的待办页
- 设置页可调：倒计时时长、提示内容、开机自启、倒计时模式、深浅色胶囊背景色

## 开发说明

- 插件是 esbuild 打包产物，直接改 `main.js` 即可生效
- 改完用 `node --check main.js` 验证语法，Obsidian 里 `Reload app without saving` 生效
- 数据存在 `data.json`（本地），不影响代码文件
- 本目录是发布源；`.obsidian/plugins/sidebar-timer/` 是使用副本，改动后记得同步

## 发布

1. 在 GitHub 上创建仓库并推代码
2. 打 tag 并创建 Release，附上 `main.js`、`manifest.json`、`styles.css` 三个文件
3. BRAT 用户即可一键安装更新
